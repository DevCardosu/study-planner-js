# Study Planner JS

Aplicação web simples para organizar estudos e matérias, desenvolvida com JavaScript puro, com foco em lógica, manipulação do DOM e gerenciamento de estado no front-end.

O projeto permite adicionar matérias, marcar como concluídas, deletar e acompanhar um resumo geral dos estudos.  
Os dados são persistidos utilizando LocalStorage, sem necessidade de backend.

---

## Funcionalidades

- Adicionar matérias com:
  - Meta
  - Nome da matéria
  - Prioridade
- Listar matérias dinamicamente
- Marcar matérias como concluídas
- Deletar matérias
- Resumo automático:
  - Total de matérias
  - Quantidade concluída
- Persistência de dados com LocalStorage

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage
